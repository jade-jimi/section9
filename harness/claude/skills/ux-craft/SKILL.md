# UX Craft — 화면과 문구의 완성 기준

두 계보의 공통 원칙을 실행 규칙으로 정리한 것이다: **Apple HIG**(명료함·존중·깊이,
직접 조작, 시스템 일관성)와 **토스류 국내 금융/생활 제품**(한 화면 한 결정, 군더더기
제거, 실패까지 설계된 문구, 손끝 리듬). 원칙 이름을 외우는 게 목적이 아니라 **판단
기준**으로 쓰는 것이 목적이다.

## 1. 한 화면 한 결정

- 화면마다 **사용자가 내려야 할 결정 하나**를 정하고, 그 결정을 돕지 않는 요소는 뺀다.
- 선택지가 3개를 넘으면 기본값을 정해 제시하고 나머지는 접는다. "고르게 하지 말고
  정해주고 바꿀 수 있게 한다."
- 설명이 필요하면 화면을 고칠 신호다. 툴팁·안내문으로 구조 문제를 덮지 않는다.

## 2. 위계는 크기·간격·굵기로, 색은 신호로만

- 정보 위계는 타이포 스케일과 여백으로 만든다. 색은 상태·경고·강조 **신호**일 때만.
- 강조가 셋 이상이면 강조가 없는 것과 같다. 한 화면의 주 강조는 하나.
- 간격은 리듬이다: 4/8 배수 같은 고정 스케일을 쓰고 임의 값(13px, 17px)을 섞지 않는다.

## 3. 상태를 전부 디자인한다

빈 상태 · 로딩 · 부분 로딩 · 에러 · 권한 없음 · 오프라인 · 극단(0개/1개/1만 개).
- **빈 상태**는 안내가 아니라 다음 행동을 주는 자리다(버튼 하나 + 한 줄).
- **로딩**은 진행을 보여준다. 정적 문구는 멈춘 것처럼 읽힌다 — 경과·단계·스켈레톤 중
  하나는 반드시.
- **에러**는 무엇이 왜 실패했고 지금 무엇을 하면 되는지 한 문장씩.

## 4. 인터랙션 비용을 센다

- 목표까지의 **탭 수·시선 이동·되돌리기 가능성**을 세어 대안과 비교한다.
- 파괴적 행동은 확인 대신 **되돌리기**를 준다(삭제 후 "실행 취소" 5초). 확인 창은
  되돌릴 수 없을 때만.
- 입력은 최소로: 자동 채움, 붙여넣기 허용, 형식 강요 금지(전화번호 하이픈 등은 받아서
  정규화한다).

## 5. 움직임은 인과를 설명할 때만

- 애니메이션은 **어디서 와서 어디로 갔는지**를 설명하는 용도. 장식적 모션 금지.
- 지속시간 120~240ms, 감속(ease-out) 기본. 반복 애니메이션은 대기 상태에서만.
- `prefers-reduced-motion`을 반드시 존중한다.
- 레이아웃이 흔들리는 모션은 결함이다(폭 고정·자리 예약).

## 6. 문구 (ux-writer 필수)

- **사용자 언어로**: 시스템 용어(트랜스크립트·인덱스·디스패치)를 그대로 쓰지 않는다.
- 버튼은 **동사+목적**("변경 사항 저장"), 모호한 확인/취소 단독 사용 금지.
- 에러는 비난하지 않는다: "잘못 입력했습니다" → "이메일 형식이 아니에요. 예: a@b.com".
- 숫자·단위·시간은 사람 기준으로("2분 전", "1.2MB", "약 30초 남음").
- 모순 표현 금지("필수 권장"), 겹말 금지, 과장 금지.

## 7. 접근성은 기본 사양

- 대비: 본문 4.5:1, 큰 텍스트 3:1 이상. 색만으로 상태를 구분하지 않는다(모양·문구 병행).
- 키보드만으로 전 경로 도달 가능 + 포커스 링 가시. 터치 타깃 최소 44×44.
- 이미지·아이콘 버튼에 이름(alt/aria-label). 동적 영역은 상태 변화를 알린다.

## 8. 검증 없이는 완료가 아니다

- 화면 작업은 **실제 브라우저로 확인**한다(`browser-verify` 스킬 · `s9 shot`).
- 상태별 스크린샷(빈/로딩/에러/극단)을 남기고, 흔들림·잘림·대비를 눈으로 확인한다.
- 이 저장소의 대시보드를 만질 때는 **`s9-design`의 디자인 언어가 우선**한다 — 이
  스킬은 그 위의 완성도 기준이지, 시각 언어를 덮어쓰지 않는다.

## 자가 점검 (제출 전)

1. 이 화면의 결정은 하나인가? 없앨 수 있는 요소는?
2. 빈/로딩/에러/극단 상태를 다 그렸나?
3. 강조는 하나인가? 색 없이도 상태가 읽히나?
4. 되돌릴 수 있나? 파괴적 행동에 확인 대신 취소를 줬나?
5. 문구가 사용자 언어인가? 버튼이 동사+목적인가?
6. 키보드·대비·터치 타깃을 확인했나?
7. 실브라우저 캡처로 확인했나?
