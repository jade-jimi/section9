## Original

대시보드 터미널에서는 /permissions를 할 수 있게 못하나?

## Notes

### 2026-08-27T20:59:52+09:00 answer (agent: lead:claude-opus-5, by sjpark1)

`[2026-08-27 20:59:52 KST - lead]`

**대시보드 터미널에서 `/permissions` 는 안 된다.** 그건 Claude Code가 **터미널에 직접 그리는 대화형 화면**이고, 대시보드 터미널은 저에게 메시지를 보내는 통로다. 거기 `/permissions` 를 치면 Claude Code UI 가 아니라 **저에게 글자로 도착한다** — 제가 "그건 터미널에서만 됩니다"라고 답하는 데서 끝난다.

실제로 대시보드는 이미 그런 명령들을 알고 있고 `(CLI 전용)` 이라고 표시한다. **`/permissions` 가 그 목록에 없어서** 그냥 채팅으로 전송되는 상태였다. 넣었다 — 이제 `/perm` 만 쳐도 팔레트가 "CLI 전용"이라고 미리 말한다. `/hooks`·`/artifacts`·`/tasks`·`/workflows` 도 같이 넣었다.

**대시보드가 권한을 직접 편집하게 만드는 건 다른 얘기고, 저는 반대한다.** 그러면 그 화면의 API 를 **제가 `curl` 로 부를 수 있다.** 아까 제가 안 하겠다고 한 그 우회를, 이번엔 제가 만든 문으로 하게 되는 셈이다. 경계가 형식이 된다.

그래서 열려면 결국 터미널이다:

```
/permissions        → allow 에 Bash(git push:*) 추가
```
