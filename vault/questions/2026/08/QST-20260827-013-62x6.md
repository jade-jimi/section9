**아니다. 하나도 안 지웠다.** 방금 재 봤다.

```
streams 지금: 50개 · 157MB      (18:29 측정 때 50개 156MB — 그대로, 오히려 늘었다)
이 세션 미러 7.85MB · 원본 7.85MB
미러가 원본의 앞부분과 동일한가: True
차이: 6,190 바이트 — 이번 턴 이후 새로 늘어난 분
```

039 가 바꾼 건 **쓰는 방식 하나**다. 예전엔 매 턴 파일 전체를 다시 썼고, 이제는 늘어난 뒷부분만 이어 붙인다. **결과 파일은 전과 똑같다** — 위의 "미러가 원본의 앞부분과 동일한가: True" 가 그 확인이다. 지우거나 줄이는 코드는 없다.

제가 그 요청에서 말한 "미러 50개 중 원본이 사라져 미러만 남은 게 1건"은 **Claude Code 가 자기 기록을 지운 것**이지 우리가 지운 게 아니다. 오히려 그게 미러를 남겨 둘 이유였다.

**보존 기간은 여전히 없다.** 157MB 는 앞으로도 계속 는다. 오래된 미러를 줄이거나(도구 결과 본문 빼기) 기간을 두는 건 따로 판단할 일이라 039 노트에 별건 후보로만 적어 뒀다 — 지금 손대지 않았다.
