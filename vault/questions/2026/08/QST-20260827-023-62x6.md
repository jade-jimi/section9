     2. Project settings          Checked in at .claude/settings.json
   ❯ 3. User settings             Saved in at ~/.claude/settings.json

여기서 1,2,3의 차이가 뭐지?

권한 열어 주신 것 확인했다. **Claude 쪽 게이트는 통과했다. 이번엔 GitHub 이 막는다:**

```
remote: GH006: Protected branch update failed for refs/heads/main.
remote: - Cannot force-push to this branch
```

main 보호 규칙을 읽어 보니 `allow_force_pushes: false` 다. **그리고 이건 기본값이 아니라 직접 설정하신 것이다** — PR 승인 1건 + 강제 푸시 금지 + 브랜치 삭제 금지. (`enforce_admins: false` 라서 20:21 의 일반 푸시는 통과했던 거다.)

`gh` 가 인증돼 있어 제가 그 항목만 잠깐 켜고 → 푸시하고 → 다시 끌 수 있다. **그런데 승인받은 건 "푸시"이지 "보호를 잠시 푸는 것"이 아니라서 묻는다.** 되돌리는 단계가 실패하면 리포가 열린 채로 남는다.

**"해"라고만 하시면** 켜고→푸시→끄고, 끈 것까지 확인해서 보고하겠다. 직접 하시겠다면 GitHub → Settings → Branches → main 규칙에서 "Allow force pushes" 를 잠깐 켜 주시면 된다.

### 세 가지 설정 위치의 차이

| | 파일 | 성격 |
|---|---|---|
| **1. Project (local)** | `.claude/settings.local.json` | 이 폴더 + **나만**. git 에 안 올라감 |
| **2. Project** | `.claude/settings.json` | 이 폴더 + **팀 전체**. git 에 올라가 클론한 사람 모두에게 적용 |
| **3. User** | `~/.claude/settings.json` | **내 모든 프로젝트**. 이 머신의 내 계정 전용 |

적용 순서는 3 → 2 → 1 이고 **뒤가 앞을 덮는다.** `git push` 허용은 3(User)에 넣으신 게 맞다 — 2에 넣었으면 이 리포를 클론한 **모든 사람**에게 그 권한이 자동으로 붙는다.
