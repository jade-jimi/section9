## Original

⚠ Cross-session messaging is off: its socket directory could not be set up · run with --debug-file <path> to see why
이 경고가 떴는데 해결해줘.

## Notes

### 2026-08-25T23:31:33+09:00 response (agent: lead:claude-opus-5, by nicehugepark)

해결했다.

**원인** — WSL에서 systemd-logind가 로그인 세션을 만들지 않아 `XDG_RUNTIME_DIR=/run/user/1000` 이 가리키는 디렉터리가 실제로 없다. 상위 `/run/user` 는 root 소유(`drwxr-xr-x`)라 사용자가 만들 수도 없다. Claude Code가 `$XDG_RUNTIME_DIR/cc-socks` 를 만들려다 `EACCES` 로 실패해 메시징을 끈 것이다.

```
[ERROR] [uds-messaging] Failed to set up sockets directory /run/user/1000/cc-socks
  ... EACCES: permission denied, mkdir '/run/user/1000'
```

**조치** — `~/.claude/run` (0700, 사용자 소유)을 만들고 `~/.claude/settings.json` 에 추가:

```json
"env": { "XDG_RUNTIME_DIR": "/home/sjpark1/.claude/run" }
```

`CLAUDE_CODE_TMPDIR` 을 먼저 시도했으나 `XDG_RUNTIME_DIR` 이 우선순위가 높아 무효였고, 부수적으로 임시파일 경로까지 옮겨서 되돌렸다.

**검증** — 새 프로세스로 `claude -p --debug-file` 재실행: 실패 로그 0건, `[INFO] [uds-messaging] Listening: /home/sjpark1/.claude/run/cc-socks/2619.sock`.

지금 세션은 기동 시 환경이 이미 정해졌으므로 **재시작해야 경고가 사라진다.**

한 가지 남는 선택지: 시스템 차원 근본 해결은 `sudo loginctl enable-linger nicehugepark` 로 부팅 시 `/run/user/1000` 이 만들어지게 하는 것이다. Claude Code 외 다른 도구도 같은 문제를 겪고 있을 수 있으니 필요하면 직접 실행해라 (`! sudo loginctl enable-linger nicehugepark`). 그 경우 settings.json 의 env 항목은 지워도 된다.
