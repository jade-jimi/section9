TDD 시나리오 (실행: python3 tests/ note_attach)

**먼저 확인한 것**: 렌더 경로는 이미 다 있다. 본문에 `[Image: assets/<id>/f.png]`
가 있으면 문서 화면이 문서 가시성을 물려받는 `/api/asset` 로 `<img>` 를 그린다
(REQ-20260825-023/-050). `ingest_assets()` 는 절대경로를 문서 옆 `assets/` 로
옮기고 본문을 상대경로로 고쳐 쓴다.

**없는 것은 손잡이 하나다.** `s9 new` 는 ingest 를 부르지만 `s9 note` 는 안 부른다.
그래서 에이전트가 캡처를 남기는 유일한 방법이 **경로를 글자로 붙여넣는 것**이었고,
사용자는 `\\wsl.localhost\...\shots\` 를 손으로 열어야 했다. 판정하라고 부르면서
증거는 첨부하지 않은 셈이다.

정상
  N1. `s9 note <id> --attach a.png` → 노트 본문에 `[Image: assets/<id>/a.png]` 가
      남고, 파일이 실제로 그 자리에 복사된다.
  N2. 이미지가 아닌 첨부는 `[File: ...]` 로 남는다 (문서 화면이 📎 칩으로 그린다).
  N3. 여러 개를 한 번에 붙일 수 있다.

경계
  B1. `--attach` 없이 본문에 손으로 `[Image: /abs/path.png]` 를 써도 이전된다 —
      ingest 를 note 경로에도 달았기 때문이다. 같은 규칙이 두 입구에 다 적용된다.
  B2. 같은 이름을 두 번 붙여도 덮어쓰지 않는다 (`-2` 접미).
  B3. 첨부만 있고 글이 없어도 노트가 선다 — 캡처 한 장만 남기는 것이 정상 경로다.

실패
  F1. 없는 파일을 `--attach` 하면 **죽는다.** 조용히 넘어가면 '붙였다고 믿는 노트'가
      남는다 — 지금 고치려는 것과 정확히 같은 실패다.

회귀
  R1. `--attach` 없는 보통 노트는 본문·중복 억제·귀속 전부 예전 그대로다.

### 2026-08-27T13:36:07+09:00 response (by sjpark1)

**경로 대신 그림이 문서에 붙는다.**

지적하신 것이 맞았다. 렌더 경로는 원래 다 있었다 — 본문의 `[Image: assets/<id>/f.png]`
는 문서 가시성을 그대로 물려받는 `/api/asset` 로 `<img>` 가 된다(REQ-20260825-023/-050).
**없던 것은 손잡이 하나**였다: `s9 new` 는 첨부 이전(`ingest_assets`)을 부르는데
`s9 note` 는 안 불렀다. 그래서 노트에 캡처를 남기는 유일한 방법이 경로를 글자로
적는 것이었고, 판정을 청하면서 증거는 상대가 직접 열게 만들었다.

**고침**

    s9 note <REQ> --label response '확인 포인트…' --attach <캡처.png> [--attach <또>]

첨부는 문서 옆 `assets/<문서ID>/` 로 옮겨지고 문서 화면이 그 자리에 그림을 그린다.
이미지가 아니면 📎 칩으로 붙고 그 안의 글자가 검색에 걸린다(REQ-20260827-005-62x6 가
만든 경로를 그대로 탄다). `--attach` 없이 본문에 손으로 쓴 절대경로도 같은 규칙으로
이전된다 — 입구가 둘이어도 규칙은 하나다.

**없는 파일을 붙이면 죽는다.** 조용히 넘어가면 '붙였다고 믿는 노트'가 남는데,
그게 지금 고치는 실패와 정확히 같은 모양이다.

**규약도 함께 고쳤다** (다음 에이전트가 다시 경로를 적지 않도록):
`browser-verify` 스킬에 '캡처는 경로가 아니라 그림으로' 절을 넣었고, `s9-protocol`
에도 한 줄 박았다. 판정 노트(`s9 status ... review --note`)에는 **확인 포인트만**
쓰고 그림은 `s9 note --attach` 로 문서에 붙이는 것이 규약이 됐다.

**정하고 넘어간 것 하나**: 보드의 판정 카드는 확인 포인트를 글자로만 그린다(그림
없음). 카드는 '무엇을 볼지'를 한눈에 주는 자리고, 그림은 그 카드에서 문서를 열면
바로 보인다. 카드에 그림까지 넣으면 판정 5건이 화면을 덮는다. 다르게 보시면 반려해
주시라 — 카드에도 축소판을 넣겠다.

**검증**: tests/test_note_attach.py 8건(이미지/파일 구분 · 여러 개 · 본문 절대경로
자동 이전 · 동명 파일 비덮어쓰기 · 첨부만 있는 노트 · 없는 파일 즉사 · 회귀).
전체 882건 OK. 그리고 이 문서의 바로 위 evidence 노트가 실물 증거다 — 경로가 아니라
그림이 박혀 있다.
