두 검토의 권고를 전부 반영했다. 갈린 곳은 둘이었고 이렇게 정리했다 — 버튼 낱말은 designer 가 "최종 낱말은 ux-writer 몫"이라 양보해 「끝났는지 확인」, 거절 창의 세션 8자는 ux-writer 권고대로 뺐다(designer 는 툴팁에 그대로 두자고 했으나, 그 글자로 사람이 할 일이 없다는 근거가 더 강하다).

**bin/s9** — ① attached(손길) 판정 문구를 사용자 말로: "다른 곳에서 이 요청을 만지는 중입니다 — M분 전까지 움직였고, 문서에는 N분째 새 기록이 없습니다" (세션 노출 제거) ② _wake_refusal 에 attached 분기 신설(ux-writer 가 찾은 결함: 분기가 없어 정반대 문장이 떴다) — 위임·워커 busy 분기 뒤에 세워 더 구체적인 문장이 먼저 선다 ③ 카탈로그 행에 hand_mins.

**web/** — ① 조각 순서를 결정 무게순으로: 멈춤 N분 · 고친 것 있음 · 마지막 X (designer 실측: 종전 순서는 ellipsis 에 커밋 조각이 제일 먼저 잘려 근거 없는 손잡이가 됐다) ② 「커밋 있음」→「고친 것 있음」, 「닫기 검토」→「끝났는지 확인」, 툴팁 교체 ③ 손길 줄 신설(.rvpt.hand, 버튼 없음): 「손길 M분 전 · N분째 조용」 — "조용함을 감추지 않는다" 회복 ④ 진단 파라미터 ?drift·?hand=<분> 추가(designer ④: 이 화면들은 실데이터에서 캡처 순간에 거의 없다).
