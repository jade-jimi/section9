표기 없이 경로만 적힌 첨부도 그림으로 낸다. 문서 id 규칙(DOC_ID_PREFIX·TAIL)을 그대로 써서 축약 id 도 걸리고, 푸는 것은 catFind 가 맡는다. 표기와 맨 경로가 attImg() 한 함수로 같은 <img> 를 낸다. 백틱 안은 건드리지 않는다(경로 자체를 보여주려고 쓴 자리) — 앞뒤 글자를 offset 으로 본다. 표기가 먼저 자리표시자로 빠지므로 한 줄을 두 번 집을 일은 구조적으로 없다. 시험 8건 초록. 곁가지: test_assets 의 i2 가 inline() 시작점부터 1600자 창으로 계약을 보고 있어 규칙이 하나 늘자 창 밖으로 밀려 깨졌다 — 글자 수 대신 앞뒤 관계만 보도록 고쳤다. 캡처 /tmp/claude-1000/-home-sjpark1-section9/b0cce452-.../scratchpad/bare007.png
