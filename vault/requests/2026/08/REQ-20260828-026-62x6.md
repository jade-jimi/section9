## Notes

### 2026-08-28T16:32:26+09:00 plan (by nicehugepark)

사용자(16:30): "만들어지는 asset 디렉토리가 해시값이 없는 게 존재하는데 중복 발생 가능성이 있는것아닌가?"

맞다. 실측:
- 접미사 없는 첨부 폴더 5개 — REQ-20260825-012 · REQ-20260825-029 · REQ-20260827-072-62x6 · REQ-20260828-006-62x6 · REQ-20260828-007-62x6. 나머지 50개는 `-62x6` 이 붙어 있다.
- 원인은 `doc_asset_dir(doc_id)` (bin/s9:5724) 가 **부른 사람이 넘긴 문자열을 그대로** 폴더 이름으로 쓴다는 것이다. `locate()` 는 짧은 id 도 alias 로 찾아 주므로 문서는 제대로 찾고, 폴더만 짧은 이름으로 만들어진다.
- 결과 ①: **한 문서의 첨부가 두 폴더로 갈린다.** REQ-20260828-007-62x6 은 짧은 폴더에 7개, 정식 폴더에 3개가 따로 있다.
- 결과 ②: 정식 id 로 물으면 못 찾는다. 실측 — `/api/asset?doc=REQ-20260828-007-62x6&f=act-review.png` → 200, `?doc=REQ-20260828-007-62x6&f=act-review.png` → **404.** 지금 화면이 안 깨지는 것은 프런트가 본문에 적힌 경로에서 id 를 그대로 떼어 쓰기 때문이지, 폴더가 맞아서가 아니다.
- 결과 ③(사용자가 물은 것): 접미사는 인스턴스 식별자다. 짧은 이름은 그것을 버리므로, 다른 인스턴스의 `REQ-20260828-007-ab12` 와 이 저장소의 `-62x6` 이 **같은 폴더 이름으로 겹친다.** 인스턴스 간 병합에서 실제 충돌이 난다.

고칠 자리: 폴더 이름을 부른 사람의 문자열이 아니라 **문서의 정식 id** 로 정한다. 그리고 이미 갈린 5개를 합치고 본문 참조를 함께 고쳐 쓴다 — 참조만 두고 파일을 옮기면 화면이 깨진다.
