```python
### ── 소스 파일 열람 (REQ-20260828-028-62x6) ────────────────────────────────
### doc_visible 의 형제다. doc_visible 이 '주인 있는 문서'를 주인으로 가르고,
### 이것은 '주인 없는 소스'만 연다 — 그래서 me 를 인자로 받지 않는다.
### ⚠ vault/·users/·state/·index/ 는 여기 없다. 그 파일들에는 판정이 따로
###   있고(doc_visible·stream_visible·secret_keys), 여기로 내주면 그 판정들이
###   전부 옆문으로 무효가 된다. 뿌리를 늘리기 전에 이 줄을 읽어라.
CODE_ROOTS = ("bin", "docs", "harness", "tests", "web")
CODE_FILES = ("CLAUDE.md", "README.md", "pyproject.toml")
CODE_EXT = (".py", ".md", ".html", ".css", ".js", ".json", ".toml",
            ".txt", ".sh", ".cmd", ".yml", ".yaml")
CODE_MAX_BYTES = 4 * 1024 * 1024     # web/guide.html 1.7MB 가 최대 실물
CODE_MAX_LINES = 400                 # 한 응답이 낼 수 있는 줄 수 상한


def _code_shape_ok(rel):
    """경로 '모양'만 본다 — 파일시스템을 만지지 않는다.
    정규화 전(글자)과 후(실경로) 두 번 부른다. 한 번만 부르면 심링크가 샌다."""
    if not rel or len(rel) > 512 or "\0" in rel:
        return False
    segs = rel.split("/")
    if any(s in ("", ".", "..") or s.startswith(".") for s in segs):
        return False          # 빈 조각·상대참조·점파일(.git/.claude/.github)
    if len(segs) == 1:
        return segs[0] in CODE_FILES
    if segs[0] not in CODE_ROOTS:
        return False
    base = segs[-1]
    if "." not in base:       # 확장자 없는 것은 bin/ 바로 밑에서만 (bin/s9)
        return segs[0] == "bin" and len(segs) == 2
    return base.lower().endswith(CODE_EXT)


def code_visible(rel):
    """소스 파일 열람 판정. 통과하면 절대경로, 아니면 "" — 이유는 돌려주지 않는다.
    (없는 것과 막힌 것을 구분해 주면 그 차이가 곧 목록이 된다.)"""
    rel = (rel or "").replace("\\", "/").strip()
    if rel.startswith("/") or re.match(r"^[A-Za-z]:", rel):
        return ""                                   # 절대경로 주입
    if not _code_shape_ok(rel):
        return ""
    root = os.path.realpath(ROOT)                   # ROOT 는 S9_ROOT 로 바뀔 수 있다
    full = os.path.realpath(os.path.join(root, rel))
    try:
        if os.path.commonpath([full, root]) != root:
            return ""                               # 리포 밖 (5978행과 같은 관용구)
    except ValueError:
        return ""                                   # 드라이브가 다름(Windows)
    # 실경로로 같은 모양 검사를 한 번 더 — 모양 검사는 심링크를 모른다.
    # web/x.html -> ../users/.../settings.json 이 여기서 죽는다.
    if not _code_shape_ok(os.path.relpath(full, root).replace(os.sep, "/")):
        return ""
    if not os.path.isfile(full) or os.path.getsize(full) > CODE_MAX_BYTES:
        return ""
    return full
```

### 4. 다중 사용자 — 누가 보나

**등록 사용자 전원. admin 제한을 걸지 않는다.**

근거: 허용 뿌리 다섯 개의 내용물은 (a) 사람마다 다르지 않고, (b) 이 인스턴스에서는 이미 **공개 GitHub 에 있는 바로 그 바이트**다(`github.com/nicehugepark/section9`, PUBLIC 확인함). admin 만 열면 GitHub 에서 누구나 읽는 파일을 대시보드에서만 가리는 셈이라 보안이 아니라 연극이고, "터미널에 나온 경로를 눌러 본다"는 기능 자체가 대부분의 사용자에게 죽는다.

**인스턴스 저장소에서는 답이 달라지나 — 허용목록은 안 달라지고, 스위치가 하나 필요하다.** 뿌리를 *디렉터리로 고정*했기 때문에 private fork 가 `ops/`·`infra/` 를 추가해도 자동으로 열리지 않는다. 달라지는 경우는 하나뿐이다: 포크가 **`bin/` 안에** 인스턴스 고유의 것(사내 엔드포인트·계정명·배포 스크립트)을 넣는 경우. 그래서 계정 설정이 아니라 **인스턴스 설정**으로 `code_read: on|off`(기본 on) 하나만 두고, off 면 `code_visible` 이 무조건 `""` 를 돌려준다. 사용자별 등급은 두지 않는다 — 등급을 두면 "코드에 주인이 없다"는 이 판정의 전제가 흐려지고, 그 순간 `vault/` 를 뿌리에 넣자는 말이 논리적으로 가능해진다.

### 6. 하지 말아야 할 것 (범위를 줄이는 쪽)

기능 전체를 접을 이유는 없다. 다만 **접어야 할 세 조각**이 있다:

- **파일 전체를 새 탭으로 여는 길을 만들지 마라.** 리드의 판단(줄 언저리 미리보기)이 보안적으로도 맞다. 전체 보기를 열면 상한·창(window)·비용 논의가 전부 무의미해지고, 다음 요청은 반드시 "그럼 편집도"가 된다.
- **`?path=` 를 받는 범용 뷰어로 일반화하지 마라.** 이 API 의 이름은 `/api/code` 이고 뿌리는 코드다. `/api/file` 이 되는 순간 허용목록은 유지되지 않는다.
- **"추적 여부"를 조건에 넣지 마라.** 방금 만들어 커밋 전인 `tests/test_새것.py:12` 를 못 여는데, 정작 막아야 할 `vault/`·`state/sessions/` 는 추적되어 통과한다. 방향이 정확히 반대다.

### 7. 이번 건과 별개로 나온 것 두 개 (리드가 REQ 로 떼 주길)

**(A) 어제 결정이 화면이 아니라 리포에서 이미 뒤집혀 있다.** `users/nicehugepark/config/settings.json` 은 추적될 뿐 아니라 **`origin/main` 에 올라가 있고 그 리포는 PUBLIC** 이다. 안에 `external_secrets_path: /home/sjpark1/s9-secrets` 가 있다. 재현: `git ls-tree -r origin/main --name-only | grep users/nicehugepark/config/settings.json` → `git show origin/main:users/nicehugepark/config/settings.json`. REQ-20260828-012-62x6 는 화면에서 "값도 경로도" 막았는데 리포가 경로를 준다. DOC-20260827-006-62x6 의 세 층 기준을 그대로 적용하면 이 키는 `permissions` 와 같은 칸("그 자체가 비밀 / 능력을 연다")이다 — **리포에 싣지 않는다**가 답이다. 클래스 단위 수정: `secret_leak` 이 값만 보지 말고 `external_secrets_path` 같은 **비밀 위치 키**를 추적 대상 설정에서 잡아야 하고, 동기화 대상 설정 키에 허용목록(DOC-006 의 `env` 방식)을 그대로 적용해야 한다. 자격증명 자체는 전수 검색 결과 **추적 파일에 0건**이다(토큰/키/사설키 패턴 전부) — 값은 안 샜고 위치만 샜다.

**(B) `Host`/`Origin` 검증이 어디에도 없다.** `grep` 결과 0건이고 `--host` 는 인자로 열려 있다. DNS 리바인딩이면 사용자가 방문한 아무 페이지나 `http://127.0.0.1:9909/api/*` 를 same-origin 으로 읽는다 — 뷰어는 서버 기동 계정(여기서는 admin)이다. 이건 `/api/doc` 부터 이미 그런 상태이고 이번 기능이 만든 것이 아니지만, **소스 읽기를 붙이면 폭이 리포 전체로 넓어진다.** 값싼 대응은 한 줄이다: `do_GET`/`do_POST` 초입에서 `Host` 헤더가 `127.0.0.1|localhost|[::1]` (+포트)가 아니면 421/404. 위 6절의 루프백 조건은 그 절반짜리 임시방편이다.

### 8. 내가 틀렸다는 걸 어떻게 알아채나

- **`CODE_ROOTS` 에 줄이 하나 늘어나는 커밋이 나오면** 내 전제("다섯 개로 충분하다")가 틀린 것이다. 7-③ 시험이 그때 빨개지므로 조용히 넘어가지 않는다. 그 시점에 늘리는 대신 다시 판정하라.
- **서버 로그의 `/api/code` 404 가 특정 경로군으로 몰리면** 막을 것을 막은 게 아니라 쓸 것을 막은 것이다(예: 사람들이 `projects/section9/CONTEXT.md` 를 계속 두드림). 나는 `projects/` 를 일부러 뺐다 — 프로젝트 멤버십 축이 있어서다. 두드림이 잦으면 그 판단이 틀린 것이고, 답은 뿌리 추가가 아니라 `project_can` 을 태우는 별도 판정이다.
- **허용 뿌리 안에서 비밀·절대경로·이메일이 하나라도 나오면** "이 뿌리에는 주인이 없다"가 무너진다. 지금은 0건임을 확인했다(`git ls-files bin web tests docs harness | xargs grep -lE '<비밀 패턴>'`). 이 grep 을 커밋 훅이나 주기 점검에 붙여 두면 전제가 깨지는 날을 자동으로 알 수 있다.
- **이 리포가 private 로 바뀌거나 포크가 `bin/` 에 인스턴스 고유의 것을 넣으면** "이미 GitHub 에 공개된 바이트"라는 4절의 근거가 사라진다. 그때는 `code_read: off` 가 기본이 되어야 한다.
- **가장 확실한 반증**: 작업 중 커밋 전 워킹트리에 붙여넣은 토큰은 이 판정이 못 막는다. 루프백 전제가 깨진 서버에서 이게 터지면 내 설계가 틀린 것이다 — 그래서 6절의 루프백 조건이 "있으면 좋은 것"이 아니라 이 판정의 **전제를 강제하는 부분**이다.
