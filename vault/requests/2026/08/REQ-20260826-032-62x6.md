## Notes

### 2026-08-26T23:45:51+09:00 response (by sjpark1)

**점은 "상태"가 아니라 "지금 이 요청에 누가 붙어 있는가"를 말한다.** 상태(open/in-progress/…)는 왼쪽 사각 배지가 맡고, 점은 살아 있는 주체를 본다.

| 점 | 뜻 |
|---|---|
| 초록 원 + 점멸 | 이 요청을 실행 중인 세션이 활동 중 (직접 신호) |
| 초록 테두리 원 | 담당 세션은 살아 있으나 이 요청의 직접 신호는 없음 |
| 호박 원 + 점멸 | 무인 워커가 기동됨 — 아직 클레임 전 |
| **붉은 네모** | **처리 주체가 죽었다** (`spawn_failed`) |
| 호박 테두리 네모 | 진전이 끊겼다 (`stalled`) |
| 회색 원 | in-progress 인데 스트림이 조용함 |

원=살아있음 / 네모=멈춤 으로 **모양까지 갈라 놨다**. 점멸은 살아있는 것만 한다.

**캡처의 붉은 네모(REQ-20260826-021-62x6)가 실제로 뜻한 것**: 무인 워커가 담당 세션 `dc4f4d76` 에 `claude --resume` 으로 붙으려다 3회 연속 실패했다 — `Error: Session … is currently running as a background agent (bg).` 그 세션이 백그라운드 에이전트로 잡혀 있어 재개가 거부됐다. 이후 시간당 스폰 한도에 걸려 30초마다 `SKIP(cap)` 만 찍었다. 근본 결함은 REQ-20260826-035-62x6 로 분리해 고쳤다.
