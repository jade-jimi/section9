지금까지 수집한 문서를 기반으로, 사용자의 5개 질문에 정확하게 답하겠습니다.

**1. `~/.claude/agents/*.md` 사용자 레벨 서브에이전트는 Task/Agent 도구로 스폰 가능한가?**

**예, 가능합니다.** 문서의 "Scope Precedence" 섹션에 명시되어 있습니다:
```
1. Managed settings (organization-wide)
2. --agents CLI flag (current session)
3. .claude/agents/ (project - check into git)
4. ~/.claude/agents/ (user - all projects)
5. Plugin agents/ directory
```
`~/.claude/agents/`의 에이전트는 스폰 가능한 대상입니다. 프로젝트 `.claude/agents/`의 에이전트와 동일하게 작동합니다(프로젝트 것이 우선 순위가 높을 뿐).

---

**2. 이 정의들은 언제 로드되는가? 세션 시작 시점에만 고정되는가?**

**문서에서 명확하게 명시되지 않았습니다.** 다만, `/context` 커맨드로 현재 로드된 subagents를 확인할 수 있다는 점과, `/doctor` 커맨드가 "subagent files Claude Code skips"를 확인한다는 설명("Check an `agents` directory **before a session starts**")은 **세션 시작 시점에 스캔한다**는 강한 힌트입니다. 

세션 도중 추가된 에이전트가 Task/Agent 도구에서 인식되지 않는 현상(사용자 관찰)은 이 메커니즘과 일치합니다: 에이전트는 세션 초기화 시에만 발견된다고 합리적으로 추론할 수 있습니다.

---

**3. 인세션에서 새 에이전트를 리로드할 방법이 있는가?**

**문서에는 명시된 방법이 없습니다.** `/context`, `/skills`, `/hooks`, `/mcp`, `/doctor`, `/debug` 등 여러 진단 커맨드가 있지만, 에이전트만 인세션 리로드하는 `/agents` 또는 유사 커맨드는 발견되지 않았습니다. 

유일한 대안은 **세션을 재시작**하는 것입니다 (`claude --resume` 후 새 세션).

---

**4. 유효한 형식의 `~/.claude/agents` 에이전트가 available 목록에 없는 다른 원인이 있는가?**

**가능한 원인들:**

a) **frontmatter 형식 오류**: `name`과 `description` 필드가 필수입니다. 이 둘 중 하나가 없으면 에이전트가 스킵될 수 있습니다.

b) **파일 위치**: `~/.claude/agents/*.md`이어야 합니다. 중첩 폴더(예: `~/.claude/agents/subfolder/agent.md`)는 발견되지 않을 가능성이 있습니다.

c) **이름 형식**: 문서에서 `name`은 "lowercase, hyphens only" 권장입니다. 대문자나 특수문자가 파싱 실패를 일으킬 수 있습니다.

d) **세션 캐싱**: 에이전트가 세션 시작 후에 추가되었다면, 현재 세션의 available 목록에는 나타나지 않습니다(사용자의 현상과 일치).

---

**5. 설치 스크립트가 보장해야 할 것은?**

문서에는 설치 스크립트에 대한 구체적 가이드가 없습니다. 하지만 다음을 권장할 수 있습니다:

a) **에이전트 배치 시점**: 세션 시작 **전에** `~/.claude/agents/` 에이전트를 모두 설치해야 합니다 (사용자가 이미 관찰함).

b) **검증**: 설치 후 `claude doctor`를 실행하여 에이전트 파일 형식과 중복 이름을 확인할 수 있습니다.

c) **명시적 재시작**: 에이전트 설치 후 사용자에게 **새 세션을 시작하도록 안내**합니다.

### 정확한 사실 확인 결과

### 1. `~/.claude/agents/*.md` 사용자 레벨 서브에이전트는 Task/Agent 도구로 스폰 가능한가?

**답: 예, 가능하다.** 다만 **조건**이 있다.

- 사용자 레벨 `~/.claude/agents/`의 agents는 scope precedence에서 프로젝트 `.claude/agents/` 다음에 로드되며, 모든 프로젝트에서 사용 가능하도록 설계됨
- 프로젝트 `.claude/agents/`의 agents는 더 높은 우선순위를 가짐 (같은 이름이면 프로젝트 것이 사용자 것을 오버라이드)
- 하지만 **세션이 시작된 후 추가된 파일은 스폰 불가**

### 2. 이 정의들은 언제 로드되는가? 세션 중 추가된 파일은 재시작 전까지 불가인가?

**답: 명확하게 예이다.** 

WebSearch 결과(공식 출처 기반): **"Subagent files are read at session start. If you add or edit a definition directly on disk, you need to restart the session to load it."**

즉:
- Agents는 **세션 시작 시점에만** 스캔됨
- 세션 초기화 후 파일을 추가하면 재시작까지 로드되지 않음
- 현재 실행 중인 세션에서 26개의 agents를 심볼릭 링크로 설치했다면, 그 agents는 이 세션에서 스폰 불가 — 다음 세션부터 가능

### 3. 전체 재시작 없이 인세션에서 새 에이전트를 리로드할 방법이 있는가?

**답: 문서에서 공식적으로 확정되지 않음.** 불확실하다.

- 현재 v2.1.198+의 `/agents` 커맨드는 단순히 reminder를 출력할 뿐, agent 관리 UI를 제공하지 않음
- WebSearch 결과에서 "subagents created through the /agents interface take effect immediately"라는 언급이 있지만, 이는 더 이상의 공식 문서에서 확인되지 않으며 과거 버전의 기능일 가능성이 높음
- **확실한 리로드 메커니즘은 문서에 명시되어 있지 않음**
- 현재 권장 방식: 클로드에게 agent 생성을 요청하거나 파일을 직접 편집 후 세션 재시작

### 4. 유효한 형식의 `~/.claude/agents` 에이전트가 available 목록에 안 나오는 다른 원인은?

**가능한 원인들:**

1. **frontmatter 형식 오류**: `name`, `description` 필수 필드 누락 또는 YAML 파싱 실패
   - 예: frontmatter가 `---` `---`로 정확히 감싸져 있지 않음
   - `name` 필드가 소문자, 하이픈만 포함하지 않음 (예: `name: My Agent` ❌ → `name: my-agent` ✓)

2. **파일 위치/소유권 검증 실패**:
   - symbolic link인 경우, 문서에서 명시한 ownership/mode check가 실패할 수 있음
   - 파일 권한이 세션을 실행한 사용자와 일치하지 않음

3. **유효성 검사 실패**:
   - `tools` 필드에 존재하지 않는 tool 이름
   - `model` 필드에 유효하지 않은 모델 ID
   - `maxTurns` 등 수치 필드가 문자열로 지정됨

4. **세션 시작 전 발견 실패**:
   - symlink를 세션 시작 후에 생성한 경우

**확인 방법**: 현재 세션에서 `/context` 커맨드를 실행하면 로드된 agents 목록을 볼 수 있음. 26개가 리스트되지 않으면 위의 원인 중 하나를 의심.

### 5. 이 문제가 다시 안 나게 하려면 설치 스크립트가 보장해야 할 것은?

**세션 시작 전에 보장할 사항:**

1. **Agent 파일을 세션 초기화 전에 배치**
   - symlink 생성 스크립트는 `claude` 명령 실행 **이전에** 완료되어야 함
   - 스크립트 실행 순서: agents 설치 → `claude` 시작 (이 순서 보장)

2. **frontmatter 검증 자동화**
   - 설치 스크립트 단계에서 각 agent 파일의 frontmatter를 파싱해서 유효성 검사
   - `name` 필드 소문자/하이픈 규칙 준수 확인
   - `description` 필드 존재 확인

3. **symlink 소유권·권한 정확성**
   - symlink 생성 후 소유권이 세션을 실행할 사용자와 일치하는지 확인
   - 파일 권한이 적절한지 검증 (일반적으로 644)

4. **선택적: 설치 후 자동 검증**
   - 설치 스크립트가 완료된 후, 다음 claude 세션 시작 전에 `/doctor` 또는 유사 검증 명령 실행
   - 또는 설치 설명서에 "설치 후 claude 세션을 시작하면 agents가 자동으로 로드됨" 명시

5. **문서화**
   - 설치 설명서에 "agents는 세션 시작 시점에만 로드된다" 명시
   - "이미 실행 중인 세션에서는 새 agents가 보이지 않으니 재시작 필요" 안내
