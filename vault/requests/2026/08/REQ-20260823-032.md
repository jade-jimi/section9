## Original

클로드 세션이 시작되면 무조건 remote-control 기능이 저절로 켜지게

## Notes

### 2026-08-23T16:35:02+09:00 decision (by sjpark1)

정정: remote-control은 모바일 앱에서 세션을 제어하기 위한 필수 기능이다. 앞서 "resume이 대체하므로 불필요"라 판단한 것을 취소한다. remote-control(모바일 제어)과 resume(크로스머신 재개)은 별개 목적이며 둘 다 구현한다.

### 2026-08-23T18:00:33+09:00 response (by sjpark1)

세션 시작시 원격제어 자동 완료: s9-install이 settings.json에 remoteControlAtStartup=true 설정(조용히 X — 최초 활성화 시 고지 메시지, --no-remote-control로 opt-out, 기존 키 보존). 다음 s9-install 실행 시 반영. remote-control은 모바일 앱/claude.ai에서 이 세션 제어용(사용자 필수 요청). 현재 settings엔 미설정 — 실제 켜려면 s9-install 재실행.

### 2026-08-23T18:03:05+09:00 response (by sjpark1)

지금 활성화 완료: s9-install 재실행으로 이 계정 settings.json에 remoteControlAtStartup=true 실제 설정됨(고지 메시지 출력 확인). 새 설치 자동 적용 검증: 깨끗한 HOME으로 s9-install 시 remoteControlAtStartup=true 자동 설정됨(새 설치자 바로 적용). opt-out은 --no-remote-control(관리자용). 모바일 앱/claude.ai 세션 제어 활성.
